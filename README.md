# Car Wash Management System

Car wash management system developed in Delphi 7 as an academic college project.

## About the Project

This project was developed as part of an academic assignment, with the goal of applying programming and software development concepts using Delphi 7.

The system aims to assist in the management of a car wash business, allowing control of information related to car washes, costs, and financial transactions.

## Features

- Car wash registration and management
- Car wash history
- Fixed cost management
- Variable cost management
- Financial management
- Reports

## Technologies Used

- Delphi 7
- Database

## Database

The database files used by the system are available in the `database` folder.

## Academic Purpose

This project was developed exclusively for academic purposes as part of college coursework.
